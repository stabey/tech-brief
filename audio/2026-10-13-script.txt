早上好，这里是技术早报，二零二六年十月十三日这一期。

先说今天最值得看的几件事。第一，X 推出统一订阅 The X Subscription，把 Grok、Cursor 和 X Premium 打包在一起，从免费档一直到每月两百美元的 Ultra，起价八美元，各产品共享每周用量池，老用户可以保留原计划，也可以按比例退款切换。第二，Meta 发布 Muse Wonder 系列模型，主打个人和专业场景的 agent 任务，带主动记忆和主动专注，Hacker News 五百多分。第三，有人在 GitHub 上提 issue，指出 Codex 命令行从零点一五七版起，默认拉起一个常驻、每小时自动更新的后台守护进程，还会复制大约三百七十多兆的安装包，呼吁改成需要手动开启，HN 四百多分。第四，欧洲多家超市的冷柜控制系统遭网络攻击，被远程设成持续除霜，法国几家大型连锁受影响，电子价签和配送也被波及。另外，开源 GIS 项目 QGIS 通过提案，正式禁止 AI 生成的贡献，评论区吵得很热闹。

特别关注三位。Elon 继续给 Terafab 招人，说这座巨型工厂的产值能排进全球国家 GDP 前二十；他还转发了统一订阅的官宣，号召大家在 Cybercab 里试试 Grok Bot。在关于「模型吞掉框架代码」的讨论里，他说特斯拉 FSD 也是这样，模型一点点吃掉了 C 加加代码；谈到强化学习时，他说有些推理轨迹读起来像人在受折磨，以后会更谨慎。Tibo 晒了 Pro 用户投票结果，说自己挺意外，原以为大家会更想要两倍用量、哪怕恢复五小时限额；面对默认上下文调整的质疑，他回应说价格降了，默认值是仔细调过的；他还透露 GPT 六点一 Sol 的 ultrafast 模式大约每秒两百五十个 token。poteto 第一时间转发统一订阅，说终于等到了，并在评论区一条条帮用户解答怎么从 Cursor 计划切换；她还聊了 agent 人设，认为人设主要是帮人管理工作、减轻心智负担。

社区一瞥：HN 上还有哈佛基于真实工程数据的研究，说 AI 编程代理写的代码更多，但软件产出并没有明显增加，代码评审成了瓶颈；Lobsters 热议 Rich Hickey 的「AI 不是工具」，以及 Linus 用 Claude Code 改进内核页缓存的新分支；V2EX 上有人吐槽 AI 改代码陷入改了又审、审了又改的死循环，也在讨论为什么大家订阅都从 Max 起步。Reddit 接口本期依旧被拦，暂缺。
